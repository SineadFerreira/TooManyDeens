## About
There are 4 main steps, fish, de-gut the fish, can the fish, sell the fish. I plan to add upgrades to each section.

## Features so far
-Player movement
-Fishing minigame
-De-gut fish with timer
-Ability to carry fish

## Planned
- Can the fish
- A truck to sell the fish
- Skill tree

## Built with
- Unity 2022.3.21f1 and C#

## Running it
1. Clone the repo: `git clone https://github.com/SineadFerreira/TooManyDeens.git`
2. Open the project in 2022.3.21f1.
3. Open the scene and press Play.
